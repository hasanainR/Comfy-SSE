# Comfy-SSE

Pipeline IO nodes for ComfyUI, built by [Sinking Ship Entertainment](https://sinkingship.ca):
load plates and sequences from anywhere, handle ACES colour on the way in and
out, and write finals to pipeline paths while still reporting previews to the
ComfyUI UI (and any frontend reading history).

```
git clone https://github.com/sinkingship/Comfy-SSE custom_nodes/Comfy-SSE
pip install -r custom_nodes/Comfy-SSE/requirements.txt
```
